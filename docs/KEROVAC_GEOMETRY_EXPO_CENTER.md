# Kerovac Geometry Expo Center

The Kerovac Geometry Expo Center is the official permanent in-game showroom for DARB primitives, objects, structure batches, and future gameplay-demo systems. It is a massive sealed civic arena attached to Kerovac rather than a temporary debug room.

## Location and Route

- Location: optional east annex off `K03 Civic Reliquary Court` in Kerovac.
- Entrance route: Kerovac main route → K03 → east through `K09 Kerovac Expo Megalithic Entrance` → `K10 DARB Geometry Expo Stadium`.
- Return route: walk west from K10 through K09 back into K03, then continue on the normal Kerovac progression route.
- The main Kerovac route through K01–K08 remains intact and the Expo Center is optional.

## Display Pad System

The stadium floor contains durable, swappable display pads with stable IDs for future Codex batches:

- Small primitive pads: `A1`–`A5`, `B1`–`B5`, `C1`–`C5`, `D1`–`D5`.
- Medium object pads: `M1`–`M8`.
- Large object pads: `LARGE-01`–`LARGE-04`.
- Very-large object pads: `VLARGE-01`–`VLARGE-02`.
- Reserved water/gameplay lane: `WATER-DEMO-LANE`.

Future batches should replace the starter preview objects only, keep the Expo Center architecture intact, and use the display pad IDs to organize best-in-show review for permanent DARB library selection.

## Starter Display Set

The initial preview set is intentionally small:

- Round and bronze-banded column candidates on `A1` and `A2`.
- A twin-column gate/frame candidate on `M1`.
- A large platform/building-demo placeholder on `LARGE-01`.
- A reserved canal-water strip for future boat, fishing, dock, bridge, and water demos.

## Materials

The Expo Center uses existing Kerovac material definitions and the `public/assets/textures/pack2/` column, arch, trim, inlay, and glyph panel textures for megalithic entrance columns, arena trim, banners, and starter columns.
